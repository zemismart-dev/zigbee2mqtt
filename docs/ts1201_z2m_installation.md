# TS1201 Zigbee2MQTT 1.4.0 单文件安装

适用精确指纹 `TS1201 / _TZ3290_qazgdsae`。现在只需要安装一个文件：**`zemismart_ts1201_ir.mjs`**。完整空调码库和许可证声明已经内置，不需要另外复制JSON或许可证文件，也不会在运行时下载码库。

## 安装及更新

1. 下载 `zemismart_ts1201_ir.mjs` 原文件，保持 `.mjs` 后缀。Z2M支持该格式。
2. 打开 Z2M 的 Settings → Dev console → External converters，保存该文件的完整内容并加载；也可将文件放入实际数据目录的 `external_converters/` 后按运行环境重载。外部JavaScript未启用的实例，先由工程人员按该版本设置启用。
3. 确认服务报告加载成功，并检查设备的型号和完整厂家指纹。然后按 [客户使用指南](ts1201_z2m_customer_guide.md) 进行品牌匹配或自学习。

Z2M 2.14.1 / zigbee-herdsman-converters26.105.0为已验证运行环境；26.109.0也完成软件回归。其他版本需单独验证。文件仍调用Z2M本身提供的模块，无需客户另装npm包。

已安装旧版时，先备份旧配置与Z2M数据目录，再覆盖同名 `.mjs`，不用重新配对。原已确认码库和学习键保存在设备元数据中；此次内置码库与1.3.0内容逐字节相同。旧的旁置 `ts1201-ir-codebooks.json` 不再被本文件读取，可以暂时保留，不要误删其他配置仍在使用的文件。

从旧版升级后，读取一次虚拟按键库状态，使已保存记录及过期控件完成初始化：在界面使用读取入口，或向实际 `BASE_TOPIC/DEVICE_NAME/get` 发送 `{"ir_key_status":""}`。该读取不发送红外。升级前先保存或放弃待保存捕获，并结束正在进行的学习或发送。

## 功能与状态

品牌逐套试机、确认匹配后生成空调面板、命名学习与独立发送按钮均保留；只改变文件交付方式。需要停止学习时使用“停止按键学习”；失败后检查连接并重试。

红外没有可靠家电状态回传。面板展示命令估计，传输完成仍需观察实际家电响应；其他遥控操作可能使估计过期。

## 维护与回滚

本文件已包含完整MIT许可证声明。仓库的 `data/` 与嵌入生成脚本仅供维护和重建，客户安装时不需要复制它们。修改内置码库会使完整性检查失败；维护人员应从原始JSON和许可证重新生成并验证，不手工编辑压缩内容。

需回退旧版时恢复那一版的完整依赖：1.3.0仍需要旁置JSON，不能把1.4.0的单文件安装方法直接用于旧版。更新配置不会代替学习数据备份，数据恢复应使用相应Z2M备份。

本次软件回归和运行加载不替代客户实机验收。原遥控器捕获、确认保存、重发与家电响应，以及其他承诺档位和断电恢复仍需现场验证。同一红外盒一次只能加入一套Zigbee网络。

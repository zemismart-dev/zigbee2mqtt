# TS1201 Zigbee2MQTT 红外遥控器使用指南

适用于已经安装单文件配置的1.4.0试点方案。先在 Z2M 中打开红外设备的“暴露功能”页；在 Home Assistant 中则打开对应的 MQTT 红外设备。

## 空调品牌匹配

1. 将红外盒正对空调，确保无遮挡。
2. 选择“空调品牌”。选择本身不发射红外。
3. 按“开始匹配”发送第一套试机码。Z2M动作按钮点ON执行；HA普通按钮直接点击。
4. 空调确有响应才按“确认匹配成功”。没有响应按“下一套码”；调整位置后需要重发同套时按“重试当前码”。

每次等当前传输结束再操作。设备报告传输完成，还需要观察家电实际响应。不会自动扫完整个品牌码库或代替你确认。

## 日常空调控制

确认有完整控制表的码库后，会出现空调电源、模式、目标温度和风速控件。可选范围以该码库为准，不支持的组合不会猜测发码。

关机时单独改温度/风速只保存待机设置；开机恢复已保存的设置。选择制冷等运行模式会启用该模式。重复确认同一已保存匹配不会重置后来的日常设置。

面板是上次命令估计，无法读取实际室温或确认空调真实开关。使用原装遥控器、原始红外码或命名按键后，实际状态可能不同；看到“估计可能过期”时先观察家电。

## 自学习遥控按键

1. 填写“按键名称”，例如“电视关机”或“空调制冷26℃”。
2. 按“开始按键学习”，看到学习提示后，将原装遥控器对准红外盒按一次对应按键。
3. 收到完整信号后，确认来自刚才的遥控器，再按“确认保存新按键”；待保存结果10分钟后失效。
4. 页面生成同名发送按钮，点击并观察家电响应后再用于日常控制。

需要结束学习时使用“停止按键学习”。若停止失败，检查设备在线和供电后重试；失败提示不能当作停止已经成功。

最多保存32个活动按键，名称1–48个字符且不能重名。选择、发送、更新、改名、删除和撤销等操作按已有按键及待保存结果出现。改名和撤销保持原按钮标识。旧的“最近学习码”不会自动变成按键，收到信号也不会自动保存。

空调通常一个按键对应完整状态；学习“制冷26℃”只能得到这个固定状态按钮，不能推导全部温度和风速。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 没有空调面板 | 完成品牌试机并确认；只有有完整控制表的码库才生成空调控件。 |
| 没有保存或发送按钮 | 先完成一次有效捕获，确认保存后才有独立发送按钮。 |
| 学习超时 | 检查遥控器电池、距离和方向，重新开始一次学习。 |
| 停止失败 | 检查红外盒在线状态，再使用停止入口重试。 |
| 传输完成却无家电响应 | 检查红外方向与遮挡，试下一候选或用原装遥控器学习。 |
| 状态与家电不同 | 红外没有可靠状态回传，按实际家电情况重新操作；不要将估计状态用于确认设备已安全关机。 |

升级与数据恢复见同包安装维护说明。软件及界面验证不替代原遥控器学习、家电响应和断电恢复验收。
